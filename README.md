📌 About The Project

Ludo Game is a web-based board game developed using front-end web technologies.

The project demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive game without using any external framework or library.

Players take turns rolling the dice and moving their tokens around the board. The objective is to move all four tokens to the finishing area before the other players.

🎮 How To Play

Step 1 — Start the Game

Open the game in your browser.

The game starts with the Red player.

Step 2 — Roll the Dice

Click the:

Roll Dice

button to roll the dice.

Step 3 — Move Your Token

When a valid move is available, the movable token will be highlighted.

Click the highlighted token to move it.

Step 4 — Get Another Turn

Rolling a 6 gives the current player another turn.

Step 5 — Capture Opponent Tokens

If your token lands on an opponent's token on a non-safe cell, the opponent's token is sent back to its home area.

Step 6 — Win The Game

The player who successfully brings all four tokens to the finishing area wins the game.

---

🎲 Game Rules

1. Every player has 4 tokens.
2. Players take turns rolling the dice.
3. A token starts moving when the player rolls a 6.
4. A player can move a token according to the dice number.
5. Rolling a 6 gives the player another turn.
6. Landing on an opponent token can capture it.
7. Tokens on safe cells cannot be captured.
8. A token cannot move beyond the finishing position.
9. The first player to finish all four tokens wins.
10. The New Game button can be used to restart the game.
