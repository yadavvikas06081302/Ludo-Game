# Premium Ludo Royale — Vikas Yadav

Responsive browser-based Ludo game using plain HTML, CSS and JavaScript.

## Run locally
Extract the ZIP and open `index.html` in a modern browser.

## GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root. Then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Features
- 2–4 local players and editable names
- Dice rolls, tokens leaving home on a six, highlighted legal moves
- Token step animation, captures, safe squares, bonus turns and win condition
- Responsive interface and no external libraries/assets
